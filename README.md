## 📜 Histoire : du goodluckOS original à goodluckOSNext

### 1. Base : goodluckOS (CodeZombie)
Le point de départ est [goodluckOS](https://github.com/CodeZombie/goodluckOS), un firmware personnalisé pour consoles GA36-MB (Allwinner A23/A33) basé sur Linux 7.2, avec RetroArch, Puppy et des noyaux Mali-400 optimisés.

### 2. goodluckOS-mali-driver (nyakaspeter)
Ajout du pilote Mali-400 GPU (ARM) pour faire tourner les jeux 3D nativement sur le matériel, avec les bibliothèques EGL/GLES2 et les modules noyau correspondants.

### 3. goodluckOS-mali-driver (nyakaspeter) → bonnes pratiques
- `glos-gpu` : lance les jeux via le driver Mali
- `glos-fbfix` : corrige le framebuffer pour ARM Mali
- `mali.ko` : module noyau ARM Mali-400

## 📦 Comment flasher

```bash
zstd -d -c goodluckOSNext.img.zst | sudo dd of=/dev/sdX bs=4M status=progress
```

Remplacez `/dev/sdX` par votre carte SD.
